2. Patient-risk patterns

A separate, explainable rules layer looks for possible emergencies, overdose, medication misuse, allergy concerns and interaction questions.

3. Browser alert

The extension surfaces a warning in supported AI chat pages. It does not automatically block or rewrite what you send.

🔐
Privacy and prototype limits

The backend does not intentionally save prompt text. Browser screening uses a local healthcare-keyword prefilter and sends text only after a pause. Do not submit real patient identifiers. This is not a medical device, emergency service, clinical triage tool or validated drug-interaction checker.
