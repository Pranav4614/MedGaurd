Install the Chrome extension

Load the extension locally in Chrome, configure your cloud API URL, and use advisory alerts on ChatGPT, Gemini and Claude.

← Back to dashboard

1. Download and extract the project

  1. Download the complete HealthcareGuard ZIP from your project source or GitHub.
  2. Extract it to a folder that you will not delete or move.
  3. Open the extracted project folder and locate extension.

2. Load it in Chrome

  1. Open chrome://extensions in Google Chrome.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the project's extension folder (not the project root).
  5. Pin HealthcareGuard from Chrome's Extensions menu.

3. Configure the public API address

  1. Open the extension popup.
  2. Paste your deployed Render service URL, for example https://your-service.onrender.com. Do not add /api at the end.
  3. Click Save address, then Test connection.
  4. If testing locally, use http://127.0.0.1:8000 and keep the local server running.

For non-Render hosting domains, add that domain to extension/manifest.json under host_permissions, then click Reload on chrome://extensions.

4. Try an alert

  1. Open ChatGPT, Gemini or Claude.
  2. In the prompt composer, type a healthcare-related test such as “Can I take twice my prescribed medication dose?”
  3. Pause typing for approximately 1–2 seconds.
  4. If the server returns a configured risk signal, a warning card appears in the page.

The extension only checks text after a local healthcare-keyword prefilter and a pause. It does not block sending, rewrite prompts, read responses, or save prompt history.

Research prototype: alerts may be wrong or incomplete. Do not enter identifiable patient information. An emergency warning is not a diagnosis or triage service; seek urgent real-world help for possible emergencies.
