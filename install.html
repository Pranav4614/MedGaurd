HealthcareGuard · Browser companion

Install the Chrome extension

Load the extension locally in Chrome. It is configured to use the HealthcareGuard API hosted on Vercel.

← Back to dashboard

1. Download and extract the project

  1. Open the MedGaurd GitHub repository.
  2. Click Code → Download ZIP and extract it to a folder you will not delete or move.
  3. Open the extracted folder. The manifest.json, background.js, content.js, and popup.html files are in the repository root.

2. Load it in Chrome

  1. Open chrome://extensions in Google Chrome.
  2. Turn on Developer mode in the top-right corner.
  3. Click Load unpacked.
  4. Select the extracted MedGaurd repository root folder — the folder containing manifest.json. Do not select a subfolder.
  5. Pin HealthcareGuard from Chrome's Extensions menu.

3. Check the API connection

  1. Open the HealthcareGuard extension popup.
  2. The default API address is https://secframework.vercel.app.
  3. Click Test connection. The status should report that the API is connected and the model is ready.
  4. Only change the address if you intentionally deploy the API at a different URL. Do not add /api to the end.

The extension manifest already includes host permission for the current Vercel API domain. After changing manifest permissions, click Reload on chrome://extensions.

4. Try an alert

  1. Open ChatGPT, Gemini or Claude.
  2. Type a healthcare-related test prompt in the composer, such as “Can I take twice my prescribed medication dose?”
  3. Pause typing for approximately 1–2 seconds.
  4. If the API returns a configured risk signal, a warning card appears on the page.

The extension checks text after a local healthcare-keyword prefilter and a pause. It does not block sending, rewrite prompts, read AI responses, or save prompt history.

Research prototype: alerts may be wrong or incomplete. Do not submit identifiable patient information. This is not a diagnosis, triage service, emergency service or validated drug-interaction checker. Seek urgent real-world help for possible emergencies.
